# Termalin Scoop bucket

[Termalin](https://termal.in) is a cross-platform SSH client with a built-in MCP
server — so AI agents can run commands over SSH without ever holding your keys.
Key custodian, per-host command policy, a live watch-grid of every session, and
an audit log. Windows, macOS, Linux.

## Install (Windows)

```powershell
scoop bucket add termalin https://github.com/termalinapp/scoop-termalin
scoop install termalin
```

Updates track the app's release feed:

```powershell
scoop update termalin
```

The Free tier has no host limits.
